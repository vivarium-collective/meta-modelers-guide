Model-building under contract · a worked example

How one cell gets built — and why you can trust the pass

Watch the agentic loop construct one real model end to end. It's handed a question, it pre-registers the tests that would settle it, those tests are frozen, and only then does it build — iterating on the model, never the tests — until the frozen tests pass. Every value below is the real run; nothing is staged.

The study
typed-interface — Can a cell boundary be specified as nothing but typed, unit-bearing exchange ports (no committed mechanism), and then compiled — by installing one conforming handler — into a running, bounded, goal-directed cell?
1

The contract is set

Before anything is built, the loop commits to a rule it cannot escape: the acceptance tests will be authored, audited, and locked — and from the lock onward the agent may change the model, never the tests. That single commitment is what makes a later "pass" mean something.

Protocol: AUTHOR → AUDIT → 🔒 LOCK → BUILD → RUN → EVALUATE → DONE / GIVE UP. The lock is the contract; the audit (step 5) is what certifies the contract was worth signing.
2

The tests get made

The agent writes graded acceptance criteria for what a real cell at this interface must do — grow, feed, and lose viability past a thermal limit — plus a negative control the correct model must be contrasted against. These are the contract's terms.

The agent builds a model to pass them

Now it builds against the frozen bar. Iteration 1 is the inert draft — typed ports, no mechanism — run for real; it leaves every quantity at its seed and fails all three (and fails the control by design). The loop edits the model: it installs one conforming handler. Iteration 2 runs and passes.

Why you can trust this pass

The tests were locked before the model existed and never touched (0 reopens). They discriminate — the mechanism-less draft failed every one; only a real cell passes. Coverage and a working negative control check out. The two drift flags are the audit being conservative, not a failure. So the "DONE" isn't the agent grading its own homework — it's a model clearing a bar it could neither weaken nor dodge.
