Q Can a single metabolism interface — the ports nutrients ⇒ {biomass, energy, entropy, secretions} of Fig 6 — be realized by three genuinely different mechanisms (a lumped-yield process, a saturating-kinetic process, and a real flux-balance optimization via COBRApy) while every other part of the composite, and the interface itself, stays byte-for-byte the same?

Claim

One metabolic interface can be realized by many mechanisms — a lumped yield, saturating kinetics, or a real flux-balance solver — each producing its own distinct dynamics, without changing what the interface exposes.

Fig 6 is the paper's thesis in a single figure. When a cellular description fails, the right level of description drops from the cell to its molecules — but the *interface* that couples metabolism to the rest of the cell need not change. This study realizes that one interface three ways. The coarse handler applies a lumped yield — nutrients convert to biomass at a fixed stoichiometry, driving biomass to 4.0. The kinetic handler applies a saturating (Michaelis–Menten-like) rate on the same nutrient supply, so biomass builds more slowly to a distinct endpoint of 2.667. The FBA handler calls real COBRApy to solve a flux-balance optimization over the e_coli_core network each step; under a constant nutrient supply it grows biomass to 6.29 and, once uptake saturates growth, routes surplus carbon to acetate overflow — secretions rise to 30.4. Three interchangeable handlers, one unmoving interface, three distinct trajectories: a reader can watch the mechanism change underneath a boundary that does not move.

Test

Install three different handlers behind the same nutrients ⇒ biomass interface and run each to completion; also compile an impostor handler to test that the port contract is enforced.

Model disintegration
Measures The linear coarse-grain handler drives biomass on the shared nutrients ⇒ biomass interface to its own endpoint (exec 4.0), also emitting energy 2.4, entropy 0.8, secretions 1.6.·The Michaelis–Menten handler, on the identical interface and wiring, reaches a DISTINCT biomass endpoint (exec 2.667) — the same ports, a different mechanism, a different trajectory (handler independence, law 4).·The COBRApy flux-balance handler (LP over e_coli_core) reaches its own distinct biomass endpoint (exec 6.29) and routes surplus carbon to acetate overflow — secretions on the shared port rise to 30.4.·Negative control / compiler rejection: an impostor handler (NonConformingMetabolism) that renames the biomass output to ``growth`` with the WRONG type (``growth_rate`` not ``mass``) and drops energy/entropy/secretions is REJECTED by the compiler with a CompileError naming the missing ports (the port contract, law 2). Because it is rejected at compile time it never runs and produces no biomass observable, so a test requiring biomass MUST fail — that failure IS the interface being enforced.

Result

The three handlers produce three DISTINCT trajectories (biomass 4.0 / 2.667 / 6.29) while exposing the identical port set; the FBA handler shows acetate overflow (secretions 30.4), and an impostor that breaks the interface is rejected at compile time.

Conclusion

Claims

  • One metabolism interface (nutrients ⇒ biomass, energy, entropy, secretions), three interchangeable handlers (linear coarse-grain, Michaelis–Menten, real COBRApy LP): each produces its OWN distinct trajectory — biomass 4.0 / 2.667 / 6.29 — over identical ports and wiring. That is handler independence (law 4). The FBA handler additionally shows overflow metabolism: acetate leaves on the secretions port (0→30.4).

Evidence

  • COARSE-LINEAR-GROWTH — coarse (linear yield) → biomass 4.0, energy 2.4, entropy 0.8, secretions 1.6
  • KINETIC-SATURATING-GROWTH — Michaelis–Menten → biomass 2.667 (distinct endpoint), energy 1.6, entropy 0.533, secretions 1.067
  • FBA-OVERFLOW-SECRETION — cobra LP over e_coli_core → biomass 6.29, acetate secretions 30.4 (overflow)
  • IMPOSTOR-REJECTED — an impostor handler renaming biomass→growth (wrong type) is rejected by the compiler with a CompileError naming the missing ports (law 2)

Limitations

  • Toy-real metabolism: the three handlers share one small illustrative setup and the FBA handler uses the e_coli_core network, not a genome-scale reconstruction; magnitudes are illustrative, not calibrated.

Next steps

  • Replace the toy FBA network with a genome-scale reconstruction to test the same interface at realistic scale.
