Q Can the cellular boundary be specified as nothing but a set of typed, unit-bearing exchange ports (chemical, mechanical, electrical, thermal, plus growth rate, shape, objective, viability) with no committed mechanism, and then compiled — by installing one conforming handler — into a running, bounded, goal-directed cell whose interface is exactly the one declared?

Decision

Claim

A cell can be specified at one level by its interface — typed exchange variables such as chemical flux, force, current, heat, growth, shape, objective, and viability — without committing to the mechanism that realizes those behaviors.

A cell, viewed from the outside, is a small alphabet of exchange variables: fluxes of matter (chemical, mol·s⁻¹), forces (mechanical, N), currents (electrical, A) and heat (thermal, W), together with higher-level cellular quantities — growth rate (hr⁻¹), shape, an objective the cell pursues, and a viability that says whether the cellular description still holds. Fig 4 is that alphabet. This study makes it operational: the draft declares each port with its type and unit and promises 'a bounded, goal-directed cell'; the handler keeps the promise, uptaking chemical and converting it into growth so that shape and objective climb. Nothing about the interface changes between draft and executable — only a mechanism is installed behind it.

Test

Start with the Fig. 4 interface as an inert specification, install a bounded-cell mechanism behind it, and run the resulting composite. The compiler must preserve the declared interface exactly.

Conclusion

Claims

  • Given one conforming handler the cellular interface becomes a bounded, goal-directed cell: chemical is taken up across the interface (flux 0.0→−0.8) and drives growth, so shape climbs 1.0→4.2 and the objective rises 0.0→1.6 — coupled dynamics behind an unchanged interface, not a scripted ramp.

Evidence

  • SHAPE-GROWS — shape 1.0 → 4.2 (growth well above seed)
  • CHEMICAL-UPTAKE — chemical flux 0.0 → -0.8 (net uptake across the interface)
  • OBJECTIVE-CLIMBS — objective 0.0 → 1.6 (goal-directed progress)

Limitations

  • Single-handler toy-real model: the rate laws are real in shape but the constants are illustrative, and only this one mechanism is installed behind the interface.

Next steps

  • Install a second, independent handler behind the same interface to show mechanism-independence directly.

Limitations

  • Constants (uptake rate, yield) are illustrative, not fitted to a named organism.
